# InfluenceAI — Analysis Module

Analysis-only Streamlit project for Social Network Analysis and Influencer Marketing.

## Run
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Push this folder to GitHub, then create a Streamlit Community Cloud app using `app.py`.

The included `influencer_dataset.csv` contains 120 synthetic influencer records for demonstration/academic use.
